# Roadmap

The upstream project explicitly states that it is pre-v1 and that the implementation is built but not yet proven on real-world documents at scale.

## Current status

- the core library is implemented
- the architecture is mature and documented
- adapter modules exist for provider integration
- evaluation infrastructure is present
- real-world accuracy claims remain intentionally deferred

## Main next steps

- get real documents into the evaluation corpus
- run the evaluation harness against production-like inputs
- calibrate confidence weights
- define the first stable release policy
- prove the system under real document diversity
